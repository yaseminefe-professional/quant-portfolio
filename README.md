# Quant & Finance Portfolio

Self-built projects showing basic-to-advanced quantitative finance methods on real-time data. Built for Netherlands job applications, grounded in an MSc thesis on cryptocurrency momentum and market regimes (RSM Erasmus) and internships in real estate PE and equity research.

Each project folder is independent: its own README (problem, method, data source and limitations, how to run), its own dependencies, runnable on its own.

## Tracks

- **Track 3: Risk management & derivatives** — in progress
  1. [VaR/CVaR calculator with backtesting](track-3-risk-management/01-var-cvar-calculator) — foundation
  2. Volatility surface & option pricer — applied, not started
  3. Fixed income risk dashboard — advanced, not started
- Track 1 (quant research & algorithmic trading), Track 2 (portfolio management), Track 4 (corporate finance & valuation), Track 5 (capital markets & macro) — not started

## Data sources

Live data throughout, not static CSVs. Twelve Data for equities/FX, Binance public API for crypto, ECB Statistical Data Warehouse for EU macro and rates, Financial Modeling Prep for company fundamentals. See individual project READMEs for which source each one uses and why.
